

\# Predictive Analytics Using Historical Data



\## Project Overview

This project uses machine learning to analyze historical sales data and forecast future sales trends using Linear Regression.



\## Objectives

\- Analyze historical sales patterns.

\- Clean and preprocess datasets.

\- Build a predictive model.

\- Evaluate model performance.

\- Forecast future sales trends.



\## Technologies Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Scikit-learn



\## Algorithm

Linear Regression



\## Methodology

1\. Generate historical sales data.

2\. Handle missing values.

3\. Perform feature engineering.

4\. Split data into training and testing sets.

5\. Train the Linear Regression model.

6\. Evaluate model performance.

7\. Forecast future sales for six months.



\## Model Evaluation

\- MAE: 247.16

\- RMSE: 349.26

\- R2 Score: 0.6868



\## Future Forecast

The model predicts sales trends for November 2026 to April 2027.
